GitHub's own download counters for each zip, the same numbers the release pages count. Downloads from this page and from GitHub count alike. GitHub updates them with a delay, so a new download can take a while to show.

Before you flash

Save a full parameter backup first. Read the release notes link under the button: they say whether your parameters carry over from what you run now.

Install

  1. Unzip. Inside are arduplane.apj, arduplane_with_bl.hex, arduplane.bin and arduplane.
  2. Already on ArduPilot: in Mission Planner open Install Firmware, choose Load custom firmware and pick arduplane.apj (QGroundControl: Firmware, Advanced settings, Custom firmware file).
  3. Coming from INAV or Betaflight: put the board in DFU mode and flash arduplane_with_bl.hex with STM32CubeProgrammer or the INAV/Betaflight Configurator flasher. After that, use the .apj for updates.
  4. Connect and check the boot messages show Stratos and the version you picked.
