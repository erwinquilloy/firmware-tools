# INAV Disarm Hold Firmware (unofficial)

A one-page downloader for INAV 9 firmware with `osd_msp_disarm_hold`, so goggles that record only
while armed also record the stats screen. Not made or supported by the INAV team.

`index.html` reads the target list from the GitHub releases of
[erwinquilloy/inav](https://github.com/erwinquilloy/inav/releases) and links to the selected file.
The firmware, its patch and its GPL-3.0 license are published with those releases.
